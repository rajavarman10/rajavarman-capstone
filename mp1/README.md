## What running it does

- Sends 10 snippets × 4 strategies = 40 calls to `gpt-4o-mini` (temperature 0.0) for extraction.
- Sends 40 more calls to `gpt-4o` (temperature 0.0) as an LLM-as-judge, scoring each extraction 1–4.
- Caches both sets of results to `mp1_results_cache.pkl` / `mp1_scored_cache.pkl` after the first successful
  run, so re-running the notebook while you iterate on scoring/analysis doesn't re-spend API budget. Delete
  those two `.pkl` files (or set `USE_CACHE = False` in the setup cell) to force a fresh run — do this if you
  change any of the four prompts.
- Prints a failure-pattern analysis specifically checking the **j10 "null years" trap**: j10's snippet states
  no years requirement, so the correct extraction is `null`. Weak prompts fabricate a number (commonly 3 or 5)
  instead — the notebook flags this per strategy.
- Writes the final comparison table (overall + by-field + the j10 check) to `mp1_comparison.md`.

## Expected cost and runtime

- ~80 API calls total (40 extraction + 40 judge). Expected spend: **$0.10–$0.20**.
- Runs in well under a minute thanks to `asyncio.gather` batching all 40 calls per stage concurrently.
- If you hit `openai.RateLimitError` (unlikely at this volume), split the 40-task list into two batches of 20.

## Interpreting the results

- **Accuracy (mean of 3)** — how many of `company` / `role` / `years_experience_required` matched the golden
  set on average, per strategy (0–3 scale; divide by 3 for a 0–1 rate).
- **Parse rate** — fraction of responses that parsed cleanly into JSON. Chain-of-thought responses are the
  most likely to fail here if the parser can't find the JSON block after the reasoning text.
- **Judge score (of 4)** — `gpt-4o`'s holistic 1–4 score per extraction, averaged. Compare this against
  accuracy: if judge and accuracy disagree on a strategy, that's a real finding worth a line in the writeup
  (the judge may be more forgiving, or may be catching a fabrication the exact-match scorer missed).
- **Total cost ($)** and **Latency p50 (s)** — the practical trade-offs. A strategy with a slightly higher
  accuracy but 3–4× the token cost may not be the right default for production use.
- **j10 fabrication check** — whether each strategy invented a number for the one snippet with no stated years
  requirement. This is the single clearest signal of prompt discipline in this dataset.

## Troubleshooting

See `MP1_FAQ.md` (from the course package) for the full list. Two errors you're likely to hit:

- `RuntimeError: This event loop is already running` — you're in Jupyter; use `await run_all()` at the top
  level of a cell, not `asyncio.run(run_all())`. (Already handled this way in the notebook.)
- `json.JSONDecodeError` while debugging manually — the model wrapped its answer in ` ```json ... ``` ` fences
  or added a preamble. `parse_response()` in the notebook already strips both; if you change a prompt and see
  new parse failures, check the raw response in `results`/`scored` for the actual shape returned.
